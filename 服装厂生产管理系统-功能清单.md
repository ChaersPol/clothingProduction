# 服装厂生产管理系统 — 功能清单

> 一套在电脑和手机上都能打开使用的管理系统，把「设计 → 采购 → 裁床 → 车间 → 后道 → 仓库 → 财务」整条线连起来。
> 员工扫一下条码就能完成出入库，老板随时能看到每种货在哪个环节、还剩多少、值多少钱。

---

## 一、系统总览

| 模块          | 谁在用       | 解决什么问题                                       |
| ------------- | ------------ | -------------------------------------------------- |
| 1. 商品资料   | 设计部、仓库 | 款号、颜色、尺码、条码统一建档，全厂用同一套编码   |
| 2. 研发设计   | 设计部       | 选品、打样、算用料、算成本，知道一件衣服该卖多少钱 |
| 3. 采购管理   | 采购部       | 买了什么、多少钱、向谁买的，笔笔有记录             |
| 4. 裁床管理   | 裁床         | 裁了多少、分成几扎、每扎多少件，裁片库存在哪里     |
| 5. 车间管理   | 车间         | 哪一扎料在谁手上、产线上还有多少件没做完           |
| 6. 后道管理   | 后道         | 检验合格多少、包装入库多少，自动从产线扣数         |
| 7. 仓库管理   | 仓库         | 成品还有多少、出了多少货、货值多少                 |
| 8. 财务看板   | 老板、财务   | 哪款卖得好、库存值多少钱、赚了多少、退了多少       |
| 9. 条码与标签 | 全厂         | 生成条码、打印扎卡和吊牌，扫码代替手写             |
| 10. 系统管理  | 管理员       | 账号、权限、操作记录，谁能看什么、谁能改什么       |

## 二、商品资料

| 功能            | 说明                                                                                                                  |
| --------------- | --------------------------------------------------------------------------------------------------------------------- |
| 款号建档        | 一个款一个档：款号、父体款号、中文品名（如「卡扣束腰大摆裙」）、名称、品类、季节、图片、设计人                        |
| 颜色管理        | 维护颜色的中文名、英文名和色卡，如「黑 / Black」「Purple紫」                                                          |
| 尺码表          | 维护 S/M/L/XL 到 XXXXL 等尺码，按款自定义                                                                             |
| 商品（SKU）管理 | 按「款号 + 颜色 + 尺码」自动生成商品，一个组合就是一条库存                                                            |
| 条码管理        | 现有条码直接绑定（格式为「款号-颜色-尺码」，如 JT03-Purple紫-S，不用重贴）；没有的系统自动生成条形码或二维码          |
| 标签打印        | 两种标签：① 厂内标签——中文品名 + 款号-颜色-尺码，给包装、车间认款用；② 平台标签——带亚马逊条码，由亚马逊后台打印 |
| 初始库存导入    | 现在仓库里已有的货，用 Excel 表一次性导入系统                                                                         |

---

## 三、研发设计（设计部）

| 功能            | 说明                                                                                 |
| --------------- | ------------------------------------------------------------------------------------ |
| 选品记录        | 记录选中的款、参考图片、预计卖价                                                     |
| 款号与尺码表    | 定款号、名称、尺码表，后续全厂都用这个号                                             |
| 纸样与样衣      | 存放纸样文件、样衣照片和修改记录                                                     |
| 用料清单（BOM） | 一个款用多少面料、里布、花边、拉链、纽扣等，连损耗一起登记                           |
| 成本核算        | 面料辅料 + 加工费 + 打版费 + 拍摄 + 运营 + 头程尾程 + 海运费，自动算出厂价和建议售价 |
| 一键生成商品    | 成本确认后，自动生成这个款的所有颜色尺码商品资料                                     |

---

## 四、采购管理（采购部）

| 功能           | 说明                                                                                                                                                       |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 公用耗材采购   | 办公室、裁床、仓库、车间、后道五类耗材的采购登记（时间、名称、单价、数量、金额、供应商），每类可自定义物料明细，如唛架纸、刀片、砂带、硅油、洗水标、吊粒等 |
| 按款物料采购   | 选中款号，自动带出这个款要买的面料、辅料、配件、里布                                                                                                       |
| 采购入库       | 货到了登记入库，可以分批到货                                                                                                                               |
| 供应商管理     | 供应商名称、联系人、电话、供货内容                                                                                                                         |
| 采购查询与导出 | 按时间、类别、供应商、款号查询，一键导出 Excel                                                                                                             |
| 供应商对账     | 每个供应商一共供了多少货、多少钱、付了多少                                                                                                                 |

---

## 五、裁床管理（裁床）

| 功能         | 说明                                                                                              |
| ------------ | ------------------------------------------------------------------------------------------------- |
| 裁货开单     | 按现有制单格式开单：货号、客户、面料、里布，再按层次（铺布层）录入颜色和各尺码数量，总数自动汇总  |
| 分床分扎     | 一张单按层次分扎，一扎一个条码；每扎登记款号、颜色、尺码、数量（常见 17 件/扎，以实际裁货数为准） |
| 打印扎卡     | 每一扎打印一张卡（带条码），卡上有款号、颜色、尺码、数量、扎号                                    |
| 裁片扫码入库 | 扫扎卡，按实际裁货数确认，裁片库存自动增加（红色）                                                |
| 裁片库存查询 | 按款、颜色、尺码、扎号查看还剩多少裁片，**用红色显示**                                      |
| 补片与报废   | 裁坏了、少片了单独登记，账目清楚                                                                  |
| 裁床产量统计 | 每天裁了多少件、多少床，按人统计                                                                  |

---

## 六、车间管理（车间）

| 功能         | 说明                                                                                                         |
| ------------ | ------------------------------------------------------------------------------------------------------------ |
| 扫码领片     | 员工先在手机上点自己的名字（不用工牌），再扫扎卡，这一扎从裁片库转到「产线上」，**产线库存用蓝色显示** |
| 产线库存查询 | 随时能看到哪些款、哪些码还在产线上，还有多少件没做完                                                         |
| 完工交后道   | 一扎可分批交货：登记本次完工数，系统显示「已交 X / 共 Y」，交完自动结束；同时登记次品数                      |
| 员工产量统计 | 每个员工每天做了多少件，可做计件工资参考                                                                     |
| 超期提醒     | 某一扎在产线上放太久，系统标出来提醒                                                                         |

---

## 七、后道管理（后道）

| 功能         | 说明                                                                                                 |
| ------------ | ---------------------------------------------------------------------------------------------------- |
| 检验登记     | 登记检验了多少件、合格多少、次品多少、次品原因                                                       |
| 包装登记     | 记录包装方式、每袋装几件、谁包的                                                                     |
| 成品扫码入库 | 扫合格品，**成品库存自动增加，同时产线库存自动减少**，一步完成；一扎没交完的剩余继续挂在产线上 |
| 打印成品标签 | 每件贴标：款号、颜色、尺码加条码，客户和仓库都能扫                                                   |
| 次品处理     | 返修的回车间，不能修的直接报废，都要留记录                                                           |
| 后道产量统计 | 每天包装入库多少件，按人统计                                                                         |

---

## 八、仓库管理（仓库）

| 功能         | 说明                                                                                         |
| ------------ | -------------------------------------------------------------------------------------------- |
| 成品扫码出库 | 员工扫商品条码，登记实际出库数量，库存自动减少                                               |
| 整箱出库     | 一箱多件时按箱登记出库；箱上贴的是亚马逊平台标签，由亚马逊后台打印，系统不做箱唛             |
| 实时库存看板 | 一个页面看全厂库存：**裁片红色、产线蓝色、成品黑色**，三种颜色分得清清楚楚             |
| 库存流水     | 每一笔进出都有记录：什么时候、哪个货、多少件、谁操作的                                       |
| 出货表       | 登记款式、颜色、尺码、数量、单价、金额，另设海运费一栏（后面补填也行），自动汇总当天出货货值 |
| Excel 导出   | 库存表、出货表、流水表，随时导出 Excel                                                       |
| 库存预警     | 给每个商品设一个最低库存，低于这个数系统自动提醒补货，并可直接生成裁货建议单                 |
| 盘点         | 定期盘点，盘盈盘亏登记调整，有据可查                                                         |
| 退货入库     | 客户退回的货登记入库，好货回成品库，坏货进次品                                               |

## 九、财务看板（老板、财务）

| 功能     | 说明                                                     |
| -------- | -------------------------------------------------------- |
| 出库排行 | 商品（SKU）排行 + 父体款号排行，按数量或金额排名         |
| 库存详情 | 每个商品数量多少、值多少钱、放了多久                     |
| 利润统计 | 卖的钱减去材料、加工、运费和各种费用，算出每个款赚多少   |
| 退货统计 | 退了多少、退货率多少、主要什么原因                       |
| 费用登记 | 海运费、头程尾程、拍摄、运营等费用登记进来，利润才算得准 |

## 十、所有角色都能用的通用功能

| 功能           | 说明                                                                             |
| -------------- | -------------------------------------------------------------------------------- |
| 多人同时使用   | 至少 2 人（按 5～10 人设计）可同时操作，共用同一份库存，谁入库谁出库立刻就能看到 |
| 电脑手机都能用 | 一套系统，电脑上做管理，手机上做扫码，不用装 App，浏览器打开就用                 |
| 扫码操作       | 用手机直接扫商品上的条码，不需要额外买设备                                       |
| 操作记录       | 谁、什么时候、做了什么，全部留痕，查账有依据                                     |
| 改错留痕       | 操作错了不能直接改数字，要填原因作废重开，原记录保留，账不会乱                   |
| 权限控制       | 裁床只能操作裁床、仓库只能操作仓库，看到的内容按岗位区分                         |
| 消息提醒       | 库存不足、单据待处理，系统内消息提示                                             |

## 十一、库存的三种颜色（全厂统一叫法）

| 颜色    | 叫什么   | 意思                           |
| ------- | -------- | ------------------------------ |
| 🔴 红色 | 裁片库存 | 已经裁好、还没上车的布料       |
| 🔵 蓝色 | 产线库存 | 车间已经领走、还没做完的半成品 |
| ⚫ 黑色 | 成品库存 | 已经包装好、可以直接卖的货     |

一件货在同一时间只会在这三种状态里的一种，从红到蓝再到黑，数量对得上，账就不会错。

## 十二、已确认口径（逐条确认过）

| 项目       | 确认结果                                                                                                                                                                                                 |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 裁片怎么算 | 按整件（套）算，不分前片后片；裁工裁完按扎登记款号、颜色、尺码、数量，制作条码扎卡，扫码入裁片库（红色）                                                                                                 |
| 每扎数量   | 一扎一个码，常见 17 件/扎，以实际裁货数为准，数量不固定                                                                                                                                                  |
| 员工身份   | 在手机上点自己的名字，**不用工牌**；选中后连续扫码默认记在这个人名下，换人再点一次                                                                                                                 |
| 分次交货   | 一扎可以分批完成，系统显示「已交 X / 共 Y」，交完自动结束                                                                                                                                                |
| 平台编号   | 带条形码的（如 `X0040CV6V3`、`MQ3001-ZI00M`）是亚马逊平台编号，**不录入本系统**；箱唛由亚马逊后台打印                                                                                          |
| 标签分两种 | ① **厂内标签**：不带条形码，用中文品名 + 款号-颜色-尺码（如「原布 卡扣束腰大摆裙 / JT03-Purple紫-S」），给包装阿姨、车间认款用，避免弄错；② **平台标签**：带亚马逊条形码，由亚马逊后台打印 |
| 商品条码   | 格式为「款号-颜色-尺码」（如 `JT03-Purple紫-S`），已有条码直接绑定，**不用重新贴标**                                                                                                             |
| 标签机     | 佳博 GP-1324D 热敏条码打印机                                                                                                                                                                             |
| 库存显示   | 裁片（红）/ 产线（蓝）/ 成品（黑），同一页面分列显示                                                                                                                                                     |
| 半成品     | 就是「产线库存」，两版需求说的是同一个东西                                                                                                                                                               |
